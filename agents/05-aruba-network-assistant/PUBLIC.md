# Aruba Network Assistant — public draft

> Draft à valider. Exemple conceptuel sans environnement réel.

## Use case

A Copilot Studio assistant connected to network-management capabilities through controlled tools, helping technical teams retrieve operational context and explain network data in a conversational way.

## Design principles

- Expose only the minimum required operations.
- Prefer read-only demonstrations for public material.
- Keep tenant, endpoint and device details private.
- Make the source and freshness of operational data explicit.
- Use synthetic alerts, sites and devices in public examples.

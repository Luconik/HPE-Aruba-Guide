# Partner & Customer Reference Guide — public draft

> Draft à valider.

## Use case

A retrieval-based assistant that helps partners and technical teams locate the right official networking resource: documentation, support, lifecycle, training, labs, APIs or community content.

## Design principle

The agent should route users to authoritative resources rather than reproduce large amounts of proprietary material. Public examples should link to openly accessible official pages and use an original synthetic reference document where a knowledge source is needed.
